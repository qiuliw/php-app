# php-app

Minimal PHP Hello World with [devenv](https://devenv.sh).

## Prerequisites

- [Nix](https://nixos.org/download/)
- [devenv](https://devenv.sh/getting-started/)

## Run

Enter the environment:

```sh
devenv shell
```

CLI:

```sh
php index.php
```

Built-in server (open http://localhost:8000):

```sh
php -S localhost:8000
```
